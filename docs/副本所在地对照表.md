# 副本所在地对照表

「寻求组队显示玩家区域」上色用的数据说明。绿色 = 队长/玩家所在区域属于副本所在地。

「寻找组队筛选」的「只看副本附近」也用同一套判断：列表里会标绿的队伍才会留下。

代码里的唯一依据：`Modules/LFGWhere/LFGWhere.lua` 中的 `DUNGEON_ZONE_NAMES`。本文档只是它的可读版本，改表时以代码为准。

## 判定顺序

1. **地图链**：活动 `mapID` → `C_Map.GetMapInfo` 的 `parentMapID` 一路向上，走到大陆（`mapType <= 2`）就停；
2. **副本名**：区域名直接等于该行显示的副本名（人已经在副本里）；
3. **内置对照表**：区域名命中下表。

任一条命中即为绿色，否则金色。

## 本客户端的数据现状

诊断结果（Forever 客户端，`## Interface: 16001`）：

| 接口 | 状态 |
| --- | --- |
| `C_Map.GetMapInfo` | 存在 |
| `C_LFGList.GetActivityInfoTable` | 存在 |
| 活动 806「剃刀高地」的 `mapID` | 129 |
| `C_Map.GetMapInfo(129)` | 查不到地图信息 |

结论：客户端的地图数据里没有副本地图层，`mapID` 走不通，地图链在本客户端实际不会命中。上色主要靠内置对照表。地图链逻辑保留，换到有副本地图数据的客户端会自动生效。

另外，列表行显示的「活动名」就是副本名（如「剃刀高地」），所以对照表直接用中文名做键；带括号后缀的活动名（如「厄运之槌（东）」）会先去掉括号再匹配。

## 补充规则

- 地图链命中的范围会自动包含副本地图的所有上级区域（大陆除外）；
- 黑石山系列把「黑石山」也列进去，因为入口处 `GetRealZoneText` 可能返回黑石山；
- 靠近主城的副本把主城也算进所在地，方便在城里等人的队伍：
  血色系列 / 影牙城堡 → 幽暗城，诺莫瑞根 → 铁炉堡，死亡矿井 → 暴风城，
  哀嚎洞穴 → 奥格瑞玛，怒焰裂谷 → 奥格瑞玛 + 杜隆塔尔（城门外）；
- 诸王大厅 / 领主大厅本来就在铁炉堡地下，洛丹伦废墟就在幽暗城上方，两者都直接列了主城；
- 入口在邻接区域、队伍常在邻区集合的也加上：
  剃刀沼泽 / 剃刀高地 → 千针石林（大升降梯就在旁边），
  达拉然城 → 希尔斯布莱德丘陵（达拉然在奥特兰克与希尔斯布莱德的交界）。

## 还没收录的

- 燃烧的远征及以后版本的副本；
- 《魔兽世界：无限》后续开放的团本（2027 年春季等）；
- 其他服务器的自定义内容。

需要收录时，在 `DUNGEON_ZONE_NAMES` 里按 `<活动名> = { "<区域>", ... }` 追加即可。

活动名以游戏内列表显示的中文名为准：先 `/reload`，运行 `/lpext diag lfgacts`，窗口里会按分类列出全部活动，并标出「已收录 / 未收录」；把未收录的名字和所在地发来就能补。
